Agents must start with:

```txt
1. /dklao/AGENTS.md
2. /dklao/con_agents/AGENTS.md
3. /dklao/con_agents/AGENT_BOOTSTRAP.md
4. Task-relevant companion files
```

## Required Agent Behavior

Agents must not start implementation until they have loaded the root bridge, master rules, and task-specific controls.

Agents must not invent logos, favicon, slogan icons, fake product claims, fake prices, fake stock, or unsupported technical specifications.

Every major page must guide the customer toward a business action: quote request, rental inquiry, service booking, spare-parts inquiry, or product discovery.
